## Mau edit apa, buka file apa

| Yang diedit | File |
|---|---|
| Tampilan Home | resources/views/home.blade.php |
| Tampilan Tentang | resources/views/tentang.blade.php |
| Tampilan Dokumentasi | resources/views/dokumentasi.blade.php |
| Tampilan Welcome | resources/views/welcome.blade.php |
| Layout (kerangka halaman) | resources/views/layouts/ |
| Gaya tampilan (CSS) | resources/css/app.css |
| Alamat halaman (route) | routes/web.php |
| Gambar | public/images/ |

## Cara Menjalankan
1. Clone repo ini
2. Jalankan `composer install`
3. Salin `.env.example` menjadi `.env`, lalu jalankan `php artisan key:generate`
4. Jalankan `php artisan serve`
5. Buka `http://127.0.0.1:8000`
